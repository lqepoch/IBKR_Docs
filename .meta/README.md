# Mirror metadata

Machine-readable metadata for the committed TWS API documentation mirror.

- `manifest.json`: exact document set with official URL, local path, byte count, and SHA-256.
- `catalog.txt`: one stable local document path per line.
- `source.json`: upstream scope and path-preservation rule.

These files are generated by `scripts/sync_ibkr_docs.py` and must not be edited manually.
